# M.O.T.I.O.N. — pacote mobile

Pacote de arquivos do aplicativo M.O.T.I.O.N., projeto de tecnologia assistiva e comunicação alternativa desenvolvido como TCC.

## Conteúdo

- `MOTION_GITHUB_EXPO_GO.zip`: pacote do projeto mobile baseado em Expo.

## Como começar

1. Extraia o arquivo ZIP.
2. Instale o Node.js e o Expo CLI conforme a documentação do projeto.
3. Dentro da pasta extraída, instale as dependências com `npm install`.
4. Inicie o projeto com `npx expo start`.

> O ZIP é mantido como distribuição do projeto; consulte também o repositório [TCC](https://github.com/Mateusmfmd/TCC), que contém a versão principal documentada.
